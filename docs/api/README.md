### 1. Install Sphinx Dependencies

Add to `pyproject.toml` under `[dependency-groups]`:

```toml

dev = [
    "pytest>=8.0",
    "Pillow>=10.0",
    "sphinx>=7.0",
    "sphinx-rtd-theme>=2.0",
    "sphinx-autodoc-typehints>=1.25",
]
```

Then install:
```bash
uv sync --dev
```

### 2. Generate Module Stubs

```bash
cd docs/api
uv run sphinx-apidoc -o . ../../justdoit --separate --force
```

This creates individual `.rst` files for each module.

### 3. Create _static and _templates Directories

```bash
mkdir docs/api/_static
mkdir docs/api/_templates
```

### 4. Build Documentation

```bash
cd docs/api
uv run sphinx-build -b html . _build/html
```

### 5. Preview

```bash
start _build/html/index.html
```

## Troubleshooting

**Import errors during build:**
- Check `autodoc_mock_imports` in `conf.py` includes optional dependencies

**Module not found:**
- Verify `sys.path.insert(0, os.path.abspath('../..'))` in `conf.py`

**Missing theme:**
- Ensure `sphinx-rtd-theme` is installed: `uv add --dev sphinx-rtd-theme`
